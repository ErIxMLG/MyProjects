Мои учебные и личные проекты на Python.

- [**ColorClicker**](ColorClicker) — программа для автоматического нажатия на пиксель определённого цвета.
- [**FileRenamer**](FileRenamer) — переименование скачанной музыки, чтобы треки шли по порядку. Так удобнее переключать нужный трек в машине.
- [**googleDrive**](googleDrive) — присылает уведомление в Telegram-бота при изменении файлов в папке на Google Drive.
- [**parsing**](parsing) — простой парсер сайта с расписанием колледжа.
