ColorClicker - проект для нажатия на определенный цвет пикселя.
FileRenamer - создавал для переименования скачанной музыки чтобы она шла в порядке возрастания. Так удобнее переключать нужный трек в машине.
GoogleDrive - присылает уведомление в телеграмм бота при изменении файлов в папке на гугл диске.
Parsing - простой парсер сайта с расписанием колледжа
